# Pull request description

Readers: code reviewers. Help them review fast and safely.

Markdown sections:

## Ticket
Key and link.

## What and why
2–4 sentences.

## Changes
Bullets grouped by area, pointing to the main files.

## How to test
Commands and manual steps.

## Checklist
- [ ] Tests added/updated and passing
- [ ] Pint/lint passing
- [ ] Migrations reviewed (or none)
- [ ] Config/env changes documented (or none)

Keep it under ~60 lines. Do not paste the full diff.
